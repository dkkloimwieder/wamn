# Authoring pilot inputs

These files define the independent task inputs and grading procedure for the authoring pilot. The runner keeps grading material out of the measured agent workspace. Use the [authoring commands](../../../../docs/operations/development-loop.md#agent-pilot-authoring-experiment) to run the pilot.

- [protocol.md](protocol.md): ratified experiment procedure, scoring, and recorded amendments.
- [authoring.md](authoring.md): task format and the current runner and driver contract.
- [human.template.json](human.template.json): independently recorded human observations.
- [tasks/](tasks/): the application brief and task-specific expected outcomes.
