## Questions

1. I. How does an operator choose prod? Recommend `wamn env create <org>/<env> --prod`, an immutable choice on first provisioning. Allow an org to have zero prod rows while it sets up.
2. I. Which spelling is valid for an app path? Recommend one canonical encoded segment per `AppName`. Apply the double-hyphen ban to generated public DNS labels and retain authored API route spelling.
3. I. Which origin routes belong to control and sign-in? Recommend keeping the existing control and identity roots. Reserve their first segments and keep app administration under the app API base.
4. I. How does one sign-in span projects? Recommend keeping project authority separate and selecting the project context on each app request. Store a default app only after the discovery and session rules are set.
5. I. What happens to old Helm revisions at cutover? Recommend refusing rollback to a revision that predates the new routing contract. Continue native rollback among new revisions.
6. I. Does the GCP certificate land in Epic 6? Recommend proving org attachment on kind in Epic 6 and assigning GCP certificate-map and DNS work explicitly to the cloud epic.
