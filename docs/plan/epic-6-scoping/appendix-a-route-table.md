## Questions

1. I. How does the operator select prod, and can it move later? Recommend an explicit choice at `wamn env create` and no promotion operation in Epic 6.
2. I. Which app names can be public path segments? Recommend one canonical segment per name and an explicit rule for reserved project names before changing `AppName`.
3. I. Which root routes exist on non-prod origins? Recommend keeping password routes on every known origin and keeping the org control API, UI config, and OAuth callback at the org origin.
4. I. Can project accounts claim another project’s path inside their own env? Recommend retaining the existing same-env trust rule for this epic and refusing conflicting route records.
5. I. Which Host reaches the shared wasmCloud listener? Recommend a per-Service internal Host, subject to a two-app test on one host group.
6. I. Does the cutover support existing app Helm revisions? Recommend a fresh install unless preserving pre-T11 rollback is a requirement.
