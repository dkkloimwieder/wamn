# WAMN documentation

WAMN runs application operations from declared packages, compiled components, and selected releases. Start with the architecture overview to understand the running system. Use operations for commands, testing for methods, and plans for work that is not built. Beads holds the status of work. Historical documents preserve earlier decisions and observations.

- [Architecture](architecture/README.md): the current system, contracts, ownership, and limitations.
- [Operations](operations/README.md): development, builds, tests, and deployment commands.
- [Testing](testing/README.md): methods, expected observations, and limits.
- [Plans](plan/README.md): plans for work that is not built.
- [History](history/): superseded documents with their recorded names and references.
