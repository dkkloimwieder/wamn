# WAMN documentation

WAMN runs application operations from declared packages, compiled components, and selected releases. Start with the architecture overview to understand the running system. Use operations for commands, testing for results, and plans for each plan and its status. Historical documents preserve earlier decisions and observations.

- [Architecture](architecture/README.md): the current system, contracts, ownership, and limitations.
- [Operations](operations/README.md): development, builds, tests, and deployment commands.
- [Testing](testing/README.md): methods, expected observations, and honest limits.
- [Plans](plan/README.md): plans with their status: done, live or deferred.
- [History](history/): superseded documents with their recorded names and references.
