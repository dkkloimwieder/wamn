## Findings

**1. Each package authors JSON beside `wamn.k` that repeats it.**

Fact:

- Applications carry `publication/attachments.json` (HTTP routes, input schemas, auth policy) and `publication/components/<component>.json.in` (the component declaration with its ports and their input schemas): 64 KB across the applications.
- The input schemas repeat what `wamn.k` already declares; for example `record_receipt`'s fields and `line` list are in `wamn_receiving/wamn.k` and again as JSON Schema in both files.
- Each attachment carries a `definition-hash`; publish recomputes it and refuses a mismatch (`validate_attachment_definition_hashes`), so every definition edit needs a hash edit.
- Each `.json.in` carries `"env_key": "__ENV_KEY__"`, filled in by `component_declaration.rs`; the package artifact itself is environment-free.

Options:

- A: `wamn.k` is the one authored source. HTTP exposure and component ports are declared there (or derived from operation contracts); the build writes the publication files and computes hashes; `publication/attachments.json` and `components/*.json.in` leave Git, and the placeholder goes.

Recommend A.

**2. Package wirings exist only to choose palette components, and palette components are built into each application.**

Fact:

- `publication/wirings/*.json` (12 files) are read by one production function, `components.rs::wiring_components`, to decide which palette components to compile into the package. Workflows that run are environment rows authored through `workflow author` (tab 30).
- A palette component (`transform`, `http-request`, `jsonata`, and others) is compiled into each application that names it; `workflow_gate.rs` resolves a workflow node against the components of the release.

Options:

- A: a package lists the palette components it ships in `wamn.k`; `publication/wirings/` goes.
- B: palette components are built once with the platform, like the route guest, and every release can resolve workflow nodes against them; packages ship only their own components; `publication/wirings/` goes.

Recommend B. Inference: one build and one digest per palette component instead of one per application.
